## 機能: 最小サイトを閲覧する

開発者はクリーンな環境から静的サイトを生成・確認できる。
閲覧者はPCやスマートフォンでサイト名と準備中の説明を読める。

### シナリオ: ホームを開く

- 前提: 静的ビルドの配信先を利用できる
- もし: 閲覧者がホームを開く
- ならば: HTTP 200で日本語のページが表示される
- かつ: タイトルと主見出しは「daiksud.me」である
- かつ: 「ブログの公開に向けて準備しています。」と表示される
- かつ: ホームへのリンクから同じページに戻れる

### シナリオ: 狭い画面で読む

- 前提: 閲覧者が幅320pxの画面を利用している
- もし: 閲覧者がホームを開く
- ならば: 主見出しと説明を読める
- かつ: ページ全体の横スクロールが発生しない

自動検証は `tests/home.spec.ts` で静的ビルド後のページに対して行う。
